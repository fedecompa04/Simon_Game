# Progetto ESP 2025-26 - Consegna 1 (Intermedia)

L'applicazione consiste in un prototipo per una variante del gioco "Simon".

## Informazioni sullo sviluppo
* **Dispositivo Fisico:** OPPO A78 5G (Android 15 - API 35)
* **Emulatore:** Google Pixel 5 (Android 17 - API 37)
* **IDE:** Android Studio Otter 3 Feature Drop 2025.2.3

## Note di implementazione
Il progetto è stato realizzato in **Jetpack Compose** consultando la documentazione ufficiale e le librerie dei framework di Android e Jetpack.
